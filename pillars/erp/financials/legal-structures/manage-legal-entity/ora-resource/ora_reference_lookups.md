## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| Declared client and environment | Use core/fusion-api/rest-api-client/scripts/fusion_rest_client.py through the existing routed reference_lookup step and selected environment. Send --header REST-Framework-Version=9 on both addressGeographies and legalJurisdictionsLOV GETs. Pass q, fields, onlyData, and pagination through separate --query key=value arguments; let the client encode them. Do not pre-encode or concatenate a query URL, hardcode an environment/country, or pass placeholders literally. Preserve other endpoints' declared header policies. |
| Query value escaping | Escape single quotes in string literals by doubling them. For jurisdiction LIKE searches, escape literal backslash, percent, underscore, asterisk, and question-mark characters using the framework-version-9 backslash escape before adding the intentional outer percent wildcards. URL encoding by the client is separate from expression escaping. Use and between compound predicates. |
| Country request | Use q=CountryCode='{resolved TerritoryCode}' and GeographyType='COUNTRY' and PrimaryGeographyFlag=true; fields=GeographyIdentifierId,CountryCode,GeographyValue,GeographyType,PrimaryGeographyFlag,LanguageCode,StartDate,EndDate; onlyData=true. Do not request or filter on GeographyLevel2–5 values or those levels' language attributes and primary flags: their hierarchy joins can eliminate country rows. The current country's LanguageCode and PrimaryGeographyFlag remain permitted. Do not request hidden GeographyId or GeographyUse. |
| Country candidate and language validation | Validate exact CountryCode, GeographyType COUNTRY, PrimaryGeographyFlag true, a nonblank GeographyValue, and effective dates. Inspect all matching pages. If language-related candidates remain, present the values and languages and request explicit refinement; requery and require one result. Do not hardcode LanguageCode US, silently prefer a language, or take the first row. |
| Effective dates | Use the same applicable as-of date from the workflow throughout these lookups and record it. StartDate null or StartDate on/before as-of is valid; EndDate null or EndDate on/after as-of is valid. Null means an open boundary. Invalid date values or an inverted supplied interval fail validation. |
| Jurisdiction request | Reuse the user's identifying-jurisdiction input; ask only when it is missing. For an exact name use q=Name='{escaped supplied name}'; for a partial/contains search use q=Name LIKE '%{escaped supplied text}%'. Name='%text%' is not a contains search. Request all fields in the live lookup row, set onlyData=true, and do not add a country GeographyId filter. |
| Jurisdiction eligibility and selection | After all matching pages are read, keep only IdentifyingFlag true rows within the effective-date rule. Zero eligible rows do not resolve. One eligible row resolves subject to import-name uniqueness. For multiple eligible rows show exact Name, LegislativeCategoryCode, registration codes, and effective dates; retain IDs to distinguish records and ask the user to select. Reuse that selection rather than asking again; never select by list order. |
| Jurisdiction exact-name import uniqueness | After selection, query the selected exact Name and read all pages without identifying/date filters. If distinct JurisdictionId values share that exact Name, stop: the current CSV importer resolves by name, and even a user-selected or solely effective identifying row does not disambiguate its import. Proceed only when the current import contract demonstrably supports unambiguous selection; never manufacture an ID-based CSV override. Use the exact returned Name, not the search fragment, in both registration CSVs. |
| Geography identity and country-association limit | GeographyIdentifierId is an identifier-row key, never GeographyId. The selected jurisdiction returns its own GeographyId, but these two responses do not independently prove it matches the resolved LE country. Retain the IDs with source provenance and disclose country association as unverified; do not infer it from the name or reuse the jurisdiction's ID as a verified country identity. Fusion import still resolves the LE/main-LRU geography relationship from the supplied country/geography carriers. |
| Free-text LOV input | For lookups other than the explicitly defined jurisdiction search/selection flow, apply exact code or Unicode-normalized case-insensitive exact display matching, full pagination, active/effective eligibility, and cardinality one |
| Export use | Use export only for current shape, unchanged package parents, collision/existence checks, verification, and the exact legal-address natural-key exception |
| Physical ID returned | Retain it only as relationship evidence; never write it to CREATE |
| Function code lookup succeeds | Record the receipt but keep both function branches blocked because jurisdiction permission and authority/site coupling remain unproven |
| Receipt | Record environment, release, as-of, normalized inputs, method/path, requested fields, complete-pagination evidence, result/eligible counts, selected natural keys, source-specific receipt-only IDs, dates, derivations, and fingerprint. For both new GET contracts retain the resolved q and effective framework header; retain language refinement, user jurisdiction selection when needed, exact-name uniqueness evidence, and the unverified country-association disclosure. Redact sensitive inputs as prescribed. |
| Broader export container | A task-level export must complete successfully. A broader functional-area or offering export may have overall status Completed with errors only when its archive is available, the exact process log identifies every failed object, every object/member required by this task completed successfully with zero failed, warning, or partial rows, every failure is provably outside this task, and target, release, freshness, fingerprint, hierarchy, and headers are verified. Record and disclose the scoped exception; any required-object failure, warning, partial result, missing counter, or indeterminate status blocks. |
