### Account segment package format

Account inputs may use hyphen-delimited segments or the native FSM multiline
vector. Before candidate generation, serialize account fields to exactly 30
LF-terminated slots. Preserve leading zeros and every empty position:
`01-000--0000-000` leaves Segment3 empty and Segment4 equal to `0000`.
An empty cell remains an explicit clear; reject an all-empty nonempty vector,
more than 30 segments, malformed multiline vectors and literal escaped newlines.
This conversion does not establish GL combination validity or create a CCID.
Existing ledger-bound validation requirements continue to apply. Uploaded Invoice
Options packages must already contain the native representation; validation must
not approve hyphenated bytes by silently converting them.

## Uploaded ZIP Values and Saved Build Results

For existing rows, a populated cell changed to blank is a requested clear.
Validate it just as the same change in NLP input; do not silently preserve the
baseline value instead. Required-field and lookup checks still apply.

For generated ZIPs, retain the JSON build report and supply it with
`validate-upload --validation-context <build-report.json>`. Require the same
task, ZIP hash, and baseline hash. Match every CSV row to one original request
by its entity, exact target key, action, and saved field values. Preserve that
request's ID so its account and other lookup results remain correctly linked.
Stop on missing, changed, or ambiguous saved results.

For new rows, check the actual CSV ledger and base currency against the saved
BU/ledger results. Check required and defaulted values in the CSV itself.
Defaults added to an in-memory copy cannot fill a missing uploaded cell.
Explicit valid choices may differ from defaults. Never change uploaded bytes.

## Update preservation

For updates, `preserveOtherValues` must be `true` or omitted (defaults to `true`). Explicit `false` and nonboolean values are rejected before candidate preparation or validation. Omitted fields retain their baseline values.
