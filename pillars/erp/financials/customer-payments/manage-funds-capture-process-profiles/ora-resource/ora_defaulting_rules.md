Do not convert UI-only initialization into FSM defaults. On update preserve baseline values unless explicitly changed. EndDateDisp is a display alias: a blank display date assigns canonical 4712-12-31 for all six profile classes. Canonical EndDate representation differs by entity; consult the per-entity rows below. Do not infer all DML/export paths or treat InactiveDate as the same alias. The create path default and later explicit-null assignment are separate phases.
