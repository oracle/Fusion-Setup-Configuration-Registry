# Meals design enforcement


Use [ordinary Meals execution](../references/ordinary-meals-execution.md) for
the supported workbook and governed workflow.

## Enforcement Order

| Sequence | Step | What Must Happen |
|---|---|---|
| 1 | Resulting policy groups | Validate every compatible parent and all its rates, including retained siblings and effective periods |
| 2 | Candidate integrity | Selected rows and exact parent context only; preserve baseline metadata/nonCSV bytes |
| 3 | Native handoff | Exact final artifact evaluation, native preview and later core approval |

## Design Rules

| Applies When | Severity | Required Lookup | Blocking Condition | Recommendation | Fix Allowed? |
|---|---|---|---|---|---|
| Meals limits | Error | | Neither enabled; missing enabled amount; populated disabled amount; negative/nonfinite number | Supply applicable amounts; no implicit clearing | User input only |
| Explicit UPPER | Error | | Any supplied warning/display/prevention control other than No/N, or any supplied tolerance including zero | These fields cannot be set for an upper limit policy; derive omitted controls No and tolerances empty, resetting the same five saved fields on update | Only the mode's No/empty consequence; never overwrite conflicting user values |
| VIOLATION | Error | | Display without warning; missing active tolerance; negative value; warning not below error when both exist | Correct resulting controls/tolerances; unchanged inactive stored values may remain | User input only |
| Policy/rate groups | Error | | Existing key/status/currency/determinant change, ambiguous/duplicate full or NoStart key, reversed/overlapping inclusive periods, or missing parent/rate | Exact compatible DRAFT policies/rates, SINGLE, role/location disabled; multiple policies and nonoverlapping rates allowed | No automatic closing/deleting or key repair |
| Every candidate | Error | resolve_policy_currency | Missing bound evidence, failed planner or final artifact/metadata mismatch | Stop before native handoff; no trial/override | No |
| Expanded settings/batches | Warning | | None when local/source checks pass | Retain pending-live disclosure for batches, nonblank EndDate and expanded settings; no atomicity or broad qualification claim | No readiness promotion |
| Entertainment attendee count | Error | | Missing threshold amount/currency, attendee information enabled or rates enabled | Count mode disables attendee information and rate limits; no implicit clearing | User input only |

| Entertainment VIOLATION | Error | | Neither policy warning nor report prevention enabled | Select at least one and supply its tolerance | User input only |
| Entertainment scope | Error | | Active status, determinant inputs, currency conversion, rate deletion or implicit dependent-field clearing | Preserve editable Draft/Valid status and hidden fields; no Rate Determinants | No automatic repair |

| Airfare create preparation | Error | resolve_expanded_policy_lookup | Missing parent/rate group, explicit enforcement/display-warning/flight-class choice, customer StartDate, CATCH_ALL identity, source-bound managed/empty recipe or operation-bound lookup evidence | Use the source-qualified no-determinant profile; DRAFT and disabled flags are explicit, inactive role/duration context is deliberately null; no currency input, role sentinel, client ID or audit input | No inferred business defaults or live create qualification |

| Mileage create preparation | Error | resolve_expanded_policy_lookup | Incomplete parent/base/add-on group, explicit eligibility/add-on controls, full sixteen-coordinate identity, dynamic company evidence or source recipe | Require compatible base and enabled passenger/company rates; SINGLE/RANGE have exact distinct threshold context | No client IDs, invented threshold sentinel or unqualified company reference |
| Per Diem create preparation | Error | resolve_expanded_policy_lookup | Missing new parent/explicit ANCHOR, formula/includes/conversion/deduction choice, active component/range, matching dates or source-owned derived recipe | Admit bounded SINGLE/SUMUP/TIME_SINGLE/TIME_SUMUP groups; derive time flag, line status, lower coordinates and exact internal deduction effects | No independent workbook value target or new child/value create for existing parent |
| Per Diem unresolved create branches | Error | | New OTHER_STANDARD lower bound, equal-hour minute tie ordering or dormant time MEALS percentage-component creation | Return the precise pending branch; preserve existing compatible updates, including OTHER_STANDARD | No inferred 0:0, tie order or blanket time-profile prohibition |

After native approval verify retained integrity only: do not rebuild, requery
references or rerun rules. Partial results or undeclared/structural metadata drift require a human
completion/retry decision; never replay, repair, clean up or roll back automatically.

## Task Nodes

| Rule ID | Node Type | Sequence | Action Type | Transitions | Prerequisites | On Failure | Applies When |
|---|---|---|---|---|---|---|---|
| POLICY.DESIGN | step | 50 | design_enforcement | passed->POLICY.RULES_COMPLETE;failed->POLICY.RETURN_ISSUES | POLICY.DEFAULTS | stop | This task is requested |

Car Rental field-write uncertainty requires an exact implementor decision on the
displayed field/candidate plan before native preview. Explain the unresolved
behavior and likely failure surface. Preserve keys, audits, identities, lookup
checks and native import approval; no automatic acceptance or retry is allowed.

Accommodations follows the same task workflow with category-specific parent/rate
identities and currency evidence. Daily Limit? must remain Yes on every populated
Accommodations policy row; it is a grey workbook-only indicator, never a CSV
flag. Each resulting rate requires DailyLimit. Role, location, seasonal rate and
gender determinants are excluded; reject incompatible retained settings. Use
[Accommodations evidence](../references/accommodations-profile.json) for the
local authoring extension and its mandatory live reconciliation boundary.
