# Manage Payment Codes — Defaulting Rules

EO defaults are implementation evidence, not successful CSV omission evidence. The live FSM converter binds metadata/header fields to XML and marks root and nested VOs for explicit-null serialization. Run Book/Data Loader owns the explicit values below; it must not interpret a blank CSV cell as preserve-existing or use-default for updateable fields. Non-updateable audit/flag fields have the separate documented readXML ignore boundary below. Never replace the database-current-date behavior with the workstation date. Framework-generated language effects are distinct from direct translation inputs, which remain excluded. Sources: SRC-CS-FSM-MIGRATOR, SRC-CS-FSCORE-CSVXML, SRC-CS-FSCORE-MODELUTIL, SRC-CS-AMIMPL, SRC-INTERNAL-FSM-FAQ, SRC-CS-APPLCORE-TL-CREATE.
