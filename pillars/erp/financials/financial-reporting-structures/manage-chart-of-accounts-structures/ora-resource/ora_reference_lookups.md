# Reference Lookups

## Lookup Operations

| Resolver | Runs When | Source Values | Request Path or URL | Requested Fields | Match Rule | Values to Fill | If No Match or Many Matches |
|---|---|---|---|---|---|---|---|
| find_value_set | Before FSM export or structure package generation, for every requested segment | Explicit ValueSetCode; otherwise SegmentCode_VS lookup candidate, plus the required segment format and length | GET /fscmRestApi/resources/11.13.18.05/valueSets?q=ValueSetCode='{ValueSetCode}' | ValueSetCode, ValidationType, ValueDataType, ValueSubtype, MaximumLength, UppercaseOnlyFlag, ZeroFillFlag, SecurityEnabledFlag | A successful complete lookup returns exactly one exact ValueSetCode match with compatible ValidationType, ValueDataType, ValueSubtype, MaximumLength, and flags | Verified ValueSetCode for DefaultValueSetCode and instance ValueSetCode, compatible format and length metadata; retain ValueSetId only if returned as optional metadata | Stop structure package generation on no match, ambiguity, incompatible format or length, or a failed or incomplete lookup. Missing ValueSetId does not block a unique compatible code match; do not derive it from an opaque resource key. |
| find_chart_of_accounts | Before any FSM export, package, or create | COA Name and StructureInstanceCode; preserve a supplied code, otherwise derive StructureInstanceCode from COA Name by replacing spaces with underscores | GET /fscmRestApi/resources/11.13.18.05/chartOfAccountsLOV?q=Name='{COA Name}' or StructureInstanceCode='{StructureInstanceCode}'; required header REST-Framework-Version: 9 | Name, StructureInstanceId, StructureInstanceCode, StructureInstanceNumber, Description, EnabledFlag | Match either exact Name or exact StructureInstanceCode; zero matches means absent; exactly one means compare the existing definition | Existing instance identity for detail lookup when matched | On a successful, complete lookup with zero matches, continue to COASTR.DEFAULT for creation preparation through the declared workflow and its validation and approval gates. Compare one match, including any name/code difference, before continuing. Stop on ambiguity or a failed or incomplete lookup; never treat a lookup failure as absence. |
| get_chart_of_accounts | A unique StructureInstanceId was found | StructureInstanceId | GET /fscmRestApi/resources/11.13.18.05/chartOfAccountsLOV/{StructureInstanceId} | Name, StructureInstanceCode, StructureInstanceNumber, Description, EnabledFlag | Exact ID | Existing instance detail | Stop if the detail response is unavailable |
| resolve_segment_label_code | A segment business classification or SegmentLabelCode is supplied | Business classification, SegmentLabelCode, and complete same-task export | Read ORA_FND_APP_KEY_FLEXFIELD_STRUCTURE_SEGMENT_LABEL.csv from the complete export; use qualified KFF label metadata only when no matching export row exists | SegmentLabelCode, GlobalFlag | Exact internal code with GlobalFlag N and SegmentLabelCode not equal to GL_GLOBAL | SegmentLabelCode, GlobalFlag, allowed-domain result | Stop if the label is absent, ambiguous, global, GL_GLOBAL, or a custom label has no exported internal code |
| verify_segment_tree | TreeCode or TreeStructureCode is supplied | TreeCode, TreeStructureCode, DefaultValueSetCode | Read FND_TREE_VL and the value-set-filtered tree metadata from an approved Fusion metadata source or complete same-task export | TreeCode, TreeStructureCode, ValueSetCode | Exactly one tree with TreeStructureCode GL_ACCT_FLEX associated with DefaultValueSetCode | Verified TreeCode, TreeStructureCode, and value-set association | Stop when the tree is absent, ambiguous, uses another tree structure, or is not associated with the segment value set |
