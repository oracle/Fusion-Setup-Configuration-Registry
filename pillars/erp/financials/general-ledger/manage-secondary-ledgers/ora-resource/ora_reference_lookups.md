This file alone owns resolver mechanics. Every live call is read-only, uses the target environment and current release, follows pagination until hasMore is false, and preserves HTTP or authorization failures as resolver failures rather than value-not-found results.

## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| User supplies both ID and name | Resolve each and require they identify the same object; conflicting identifiers block. |
| Oracle REST requires q syntax | Encode the documented exact predicate as q=Field='value'; do not use contains or case-folded guessing. |
| Field projection | Use only the exact describe-backed fields above. Do not request ShortName, CalendarName, calendar EnabledFlag, PeriodName, PeriodStatus, CurrencyName, language LanguageName, language EnabledFlag, or BaseLanguageFlag from a LOV that does not expose it. |
| Accounting-period filter | Put only PeriodSetNameId in q. Read all pages, then compare PeriodType and the physical PeriodNameId locally. Do not use a semicolon-combined period-set/type q expression. |
| HTTP 400 or Oracle 29140 | Classify as a resolver contract or input-validation failure, persist the sanitized q and response, and stop. Never report an invalid field or malformed expression as value not found, and never retry the identical invalid q. |
| Response is paginated | Continue with the documented paging controls until hasMore is false before deciding cardinality. |
| Exactly one eligible match | Map only the requested authoritative fields and retain sanitized evidence. |
| Zero eligible matches | Report the field, exact supplied raw value, endpoint or local evidence source, eligibility filter, and not-found result. |
| More than one eligible match | Report ambiguity and request a more precise supported identifier; never select the first row. |
| 401 or 403 | Refresh an existing cached OAuth token once when permitted, retry the same GET once, then classify auth or authz and stop. |
| 429, timeout, or 5xx GET | Use bounded backoff only for the idempotent read; after the bound, classify transport or Fusion API failure. |
| Other HTTP, serialization, paging, or client failure | Return the original failure class and sanitized response context; never translate it to not found. |
