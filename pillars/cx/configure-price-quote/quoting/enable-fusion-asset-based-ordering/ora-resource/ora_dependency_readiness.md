# Dependency Readiness

On the allowlisted missing/null/empty catalog, insert
[ora_initial_full_publish.md](ora_initial_full_publish.md) before continuing
selective preparation. Exact Full load/job success and fresh ABO catalog
presence permit a new selective proposal. Initialization cannot satisfy the
final enabled-entity readiness or ESS gate.

| Order | Dependency | Required evidence |
|---|---|---|
| 1 | Target and process | Exact selected environment and verified Standard Process. |
| 2 | CPQ/ABO opt-ins | Both expected COMBO feature flags true; otherwise separately approve one shared update. |
| 3 | Subscription/Coverage | Check only after stage 2; both flags true. |
| 4 | CPQ preparation permission | Full ABO template and exact normal/function-only proposal approved before workbook generation/Core startup; current scope rechecked and two-hour one-use permission consumed. |
| 5 | CPQ preparation | Fixed normal/function-only workbook, Core persisted preflight and ordered task rule checks. |
| 6 | CPQ load approval | Second, independent current Core preview approved over the exact validated archive. Preparation consent cannot upload. |
| 7 | CPQ submitted | Exact receipt checkpoint; pause for explicit user status request. |
| 8 | CPQ verified | Exact load success and fresh process, enablement and function GET readbacks. |
| 9 | Companion preparation permission | Full ABO template and fixed selective proposal approved; CPQ/Fusion readiness rechecked and one-use permission consumed before workbook/preflight preparation. Parent stays cpq_completed. |
| 10 | Companion preparation | Fixed selective pair, entity metadata, concurrency and persisted task rule checks. |
| 11 | Companion load approval | Independent current Core preview approved on its exact validated archive; preparation approval cannot submit. |
| 12 | Companion submitted | Pause for explicit user load-status request. |
| 13 | Publish readiness | Verified exact load; one exact-job check, then explicit monitoring choice if pending. Repeated 15-second checks only on current consent; check-later stops. Require pinned job success and both entities enabled. |
| 14 | ESS approval/monitoring | Separate exact-payload approval, one submission, bounded exact-request monitoring. |

Submitted never means completed. Pending/unknown dependencies block later
mutations. Companion Data Loader IDs remain private; workflow checkpoints
contain only permitted non-executable provenance and status evidence.
