# ResourceUser Import and Export Reference Lookups

## REST Header Requirement

Every Fusion REST lookup in this file must include
`REST-Framework-Version: 9`, in addition to OAuth authorization and any
endpoint-specific headers.

## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| resource_user_get | Use `resolve_resource_user_by_email` or `resolve_resource_user_by_party_number` through `core.fusion-api.rest-api-client`. Require one complete exact visible item, return only requested authorized fields, and stop on zero, multiple, incomplete, unauthorized, or transport errors. Do not enter Data Loader or any write gate. |
| Resource Users GET | Include `REST-Framework-Version: 9`; use this route only for exact read-only identity and import-reference validation. No Resource Users REST Data Loader write route is available for this task. |
| Direct reportees lookup | Resolve one exact manager first, then query ResourceOrgManagerEmail using that resolved email. Paginate to completion and apply the current ResourceEndDate rule locally. This read-only branch never enters the Resource Users REST Data Loader, preview, approval, post-import ESS, or hierarchy-generation branches. |
| Attribute type, length, or description is needed | Review the Resource object in Import Objects. |
| Existing resource must be updated | Resolve its ResourcePartyNumber before preparing the CSV. |
| Resource role code is supplied | Use the active Resource Roles REST finder before preview with one exact combined role-code `q` predicate and `Rest-Framework-Version: 9`; do not rely on user confirmation or a stale export. |
| A parent manager email is outside the CSV dependency chain | Query `resourceUsers` with the exact `ResourceEmail` predicate; never scan the first page of an unfiltered collection. |
| CSV contains more than 10 data rows | Perform BusinessUnit, LegalEntity, role-code, and manager-email reference validation only for the first 10 non-header rows. Inform the user that only those rows were validated and require explicit confirmation to proceed for later rows; do not look up those rows. |
| Reporting Hierarchy Generation is eligible after import | Query fndTreeVersions through core.fusion-api.rest-api-client and validate status plus effective dates against the target current date before binding submit.argument3. |
| Export object or field is unavailable | Review existing Fusion roles and data security; do not change security configuration from this task. |
