# Manufacturing Work Centers Reference Lookups

For **Server-managed create reconciliation** in ora_design_enforcement.md,
WC.LOOKUP_WORK_CENTER runs describe_work_center_create_contract before preparing
the source. After an accepted load, WC.LOOKUP_RECONCILIATION in create_reconciliation scope uses
verify_created_work_center, resolve_plant_manufacturing_calendar,
find_applicable_work_center_calendar, find_default_route_resource_shifts, and
verify_created_subinventory. Apply WC.RECON.READBACK and WC.RECON.RESUME;
source-validation terminals are not post-load completion signals.

All executable lookups in this file are declared read-only Fusion GET requests. Task Validation must delegate every request through `core.data-loader` to the shared Fusion REST client, request only the documented fields, preserve returned identities verbatim, and apply each resolver's no-match contract. Missing prerequisites and ambiguous matches block mutations; an absent target assignment is valid for POST, and read-only verification may report absent state. No POST action is executable from this task's reference_lookup nodes.

## Request Contract

Every Fusion GET declared in this file—including collection paths, documented item URLs, and Fusion-returned `self` or `canonical` URLs—must send the exact header `REST-Framework-Version: 9` through the `core.data-loader` route. This is a package-wide requirement: no resolver may omit or substitute the header. A bodyless GET that does not use a composite key must not send a `Content-Type` request header. A documented composite-key GET must send `Content-Type: application/vnd.oracle.adf.resourceitem+json` even when it is bodyless. A composite-key request may use only already resolved authoritative field values in its documented finder or a Fusion-returned link; it never permits a client to construct an opaque item URL or opaque item-key token.

|---|---|
| Work-center creation needs a work area | Take OrganizationCode and WorkAreaCode from the business request. Do not use a user-provided WorkAreaId or WorkAreaName to override the resolved row. |
