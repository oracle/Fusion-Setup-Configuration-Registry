# Input Validation

Server-managed create eligibility and completion are governed by **Server-managed create reconciliation** in ora_design_enforcement.md. Input rows below reference that contract.

## Request Scope

The normalized scope token is the only value used by the task-node selector.

Select the import mode from the manifest dataloader_import_mode unless the active
workflow records an explicit supported override. For native FSM CSV import, use
artifact_review after validating the task/environment export metadata and the
immutable prepared package through core.data-loader. Keep native Y/N flags and
natural keys under Native FSM CSV contract below. REST DAT mappings, numeric
surrogates and REST Boolean serialization apply only to REST sources. Retain the
applicable calendar business protections for any supplied calendar rows; do not
use artifact_review to bypass them. When REST is selected, keep the existing
operational scopes and their lookups, metadata and business rules unchanged.

| Operation Scope | Accepted Intent | If Missing or Ambiguous | Next Action |
|---|---|---|---|
| work_center | Create, update, deactivate, delete, or supply-locator work that does not create or change a production-calendar association. | Stop | Provide one explicit work-center intent. |
| calendar_association | Create, update, end-date, or delete a work-center production-calendar association, including first override-calendar bootstrap. | Stop | Provide one explicit calendar-association intent. |
| calendar_resource | Create, change, or verify a work-center resource, resource-shift assignment, or availability mode. | Stop | Provide one explicit calendar-resource intent. |
| create_reconciliation | Read-only verification after a bound server-managed create load succeeds. | Stop | Provide the accepted request ID and unchanged source, expectation and target fingerprints. |
| artifact_review | Review an already prepared immutable REST Data Loader or native FSM CSV artifact without selecting a REST operational branch. | Stop | Provide the artifact identity and review intent. |

## FSM export normalization

Apply this REST conversion table only when setup_data_artifacts contains FSM exports or export
deltas selected for REST Data Loader conversion. Native FSM artifact_review preserves
the exact target-export CSV schema and flags and does not use this conversion. Direct requests use Required Groups and Field Validation without requiring
an export baseline, CSV translation rows, or a resource-master export. After
normalization, apply the same operation-scope and design policies to either input
source; export normalization does not authorize a different execution route.

| Source Input | REST Data Loader Mapping | Required Check |
|---|---|---|
| OverrideCalendarFlag | OverrideScheduleFlag | Convert explicit Y/N to lowercase true/false before source validation. A blank exported flag represents false only in this declared FSM export adapter; never default missing live state. |
