## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| A rule is enforced by the productionResources service but has no independent lookup endpoint | Use core.data-loader validation; do not infer or call an alternate API. |
| More than one candidate is returned | Stop and ask for a unique identifier. |
| No candidate is returned | Stop and ask for a valid identifier. |
| Profile or UOM lookup execution | Use core.fusion-api.rest-api-client at MFGRES.RESOLVE_UOM after the active workflow's input, selected-environment, identity and privilege checks. Let the core client encode finder values and paginate until hasMore=false; no hand-built URLs from untrusted codes. Reuse evidence only within the current preflight for the same environment, execution identity, effective date and exact candidate/profile. If the upload identity differs and equivalence cannot be verified, block. |
| A profile is not returned by profileValues | The public service exposes only profiles in its REST securing categories. Classify the value as unavailable to this route, not necessarily unconfigured. Request a user UOM when the hour profile cannot supply a default. Do not change profile values or securing categories, query a database, or switch to an internal API as a fallback. |
| Lookup fails with authorization, transport or metadata errors | Stop the affected preflight with the classified failure; do not treat failure as a missing value or authorize an inferred default. Request a UOM for unavailable hour defaulting, but still require its UOM lookup before readiness. |

## Public Sources

Checked 2026-10-27: Oracle's [26D API catalog](https://docs.oracle.com/en/cloud/saas/supply-chain-and-manufacturing/26d/api.html) still links to the 26C SCM REST guide. The 26D resource pages were unavailable, so this lookup uses the public [26C Get all organizations contract](https://docs.oracle.com/en/cloud/saas/supply-chain-and-manufacturing/26c/fasrp/op-inventoryorganizations-get.html). Verify the selected target's metadata before use.

Profile lookups use the public [26D Profile Values contract](https://docs.oracle.com/en/cloud/saas/applications-common/26d/farca/op-servername-fscmrestapi-resources-11.13.18.05-profilevalues-get.html) and its [REST exposure restrictions](https://docs.oracle.com/en/cloud/saas/applications-common/26d/farca/api-profile-values.html). The 26D and 26C UOM endpoint pages were unavailable on that date; the [26B unitsOfMeasure contract](https://docs.oracle.com/en/cloud/saas/supply-chain-and-manufacturing/26b/fasrp/op-unitsofmeasure-get.html) is the newest accessible endpoint reference used for UomCodeFinder, UOMCode and DisableDate. Verify these fields and finder against the selected environment before executing the lookup; an incompatible contract blocks this route.
