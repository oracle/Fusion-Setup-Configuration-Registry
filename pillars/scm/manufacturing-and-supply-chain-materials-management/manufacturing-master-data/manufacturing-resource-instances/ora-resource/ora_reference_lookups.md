# Reference Lookups

All resolvers in this file use `core.fusion-api.rest-api-client` for authenticated, read-only Fusion `GET` requests. Send `REST-Framework-Version: 9`; do not use a direct REST client or a different execution route. Combine q predicates with `and` using the RowMatch syntax required in framework version 2 and later; semicolon-separated version-1 predicates return HTTP 400. See [Oracle query syntax](https://docs.oracle.com/en/cloud/saas/project-management/26c/fapap/Collections.html).

## Lookup Execution Rules

| Situation | What Happens |
|---|---|
| Added domain lookup pagination | For workforce, asset and work-center collections, require items, Boolean hasMore, matching offset and a positive returned limit. Advance by that limit until explicit hasMore=false; fail on non-progress, malformed pages, repeated identities, partial scans or execution-window expiry. Escape quoted values by doubling apostrophes and pass query encoding to the shared client. Do not perform writes or supply request bodies. |
| Domain evidence | Bind all outcomes to the same selected target, request fingerprint, effective date and current validation cycle. A failed read retains its API/auth/transport class; no task-local retry or alternate endpoint. |
| Parent preflight | Use the approved read-only Fusion lookup path only to determine the parent identity and ResourceType; do not create, update, upload, or import through this lookup. |
| Parent code-and-organization preflight | Derive ResourceId only from one documented productionResources collection query using OrganizationCode='<Organization Code entered by user>' and ResourceCode='<Resource Code entered by user>' with onlyData=true and limit=1. If that query does not return an exact active ResourceId, stop; do not advance offset. |
| Parent type is EQUIPMENT | core.data-loader retains productionResources as the registered business object and prepares and validates EquipmentInstance as the only populated child resource at productionResources/{ResourceId}/child/EquipmentInstance. |
| Parent type is LABOR | core.data-loader retains productionResources as the registered business object and prepares and validates LaborInstance as the only populated child resource at productionResources/{ResourceId}/child/LaborInstance. |
| Labor person name is supplied | Use the read-only laborResourceInstancesLOV lookup with q=PartyName='<given Person, Person Name, or Party Name>'; derive PartyId only from one exact match. |
| Parent type is unsupported or unresolved | Stop before child payload preparation or import. |
