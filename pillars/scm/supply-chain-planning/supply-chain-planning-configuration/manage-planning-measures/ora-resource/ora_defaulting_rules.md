| Planning Measure GranularityId | `135` | An ordinary create-measure request, not a duplicate-origin handoff, supplies neither ordered measure levels nor GranularityId. | Enabled aggregation methods | MAX for Date or Text; SUM for every other DataTypeId | An aggregation field is enabled, or selected dimensions or DataTypeId changes. | Preserve a valid user selection; replace it only when the dependency change makes it invalid. | list_measure_aggregation_functions |
| Allocation Type (DisaggrMethodOther) | EQUAL | Allocation Type is enabled for a new non-seeded measure, has no value, and the create request is not a duplicate or a create handoff originating from duplication. Never apply this default to a duplicate, including a source with blank/null allocation. | No | list_measure_allocation_types |
