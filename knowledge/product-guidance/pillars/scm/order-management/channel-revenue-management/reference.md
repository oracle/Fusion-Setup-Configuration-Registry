# Channel Revenue Management References

Use this file for Oracle Fusion Cloud Channel Revenue Management product guidance,
including implementation, deductions and settlement, customer channel programs,
and supplier channel programs. Apply the references to the project's selected
flows, including Channel Revenue Management under Order Management and Supplier
Incentives under Procurement where applicable.

## Use first

### Implementing Channel Revenue Management

- URL: [https://docs.oracle.com/en/cloud/saas/supply-chain-and-manufacturing/26d/facri/index.html](https://docs.oracle.com/en/cloud/saas/supply-chain-and-manufacturing/26d/facri/index.html)
- Type: oracle documentation
- Category: Channel Revenue Management
- Relevance: high
- Authority: product documentation
- Freshness: version-sensitive
- Use when: Channel Revenue Management implementations that require flow selection, opt-in planning, setup sequencing, integration, security, or configuration guidance for the selected sell-side or buy-side scope.
- Do not use for: Treating implementation guidance as a replacement for detailed transactional usage instructions, assuming every optional flow is required, or authorizing setup changes or automated imports.

## Reference selection

Retain one reference for each of the four distinct guides. The implementation
guide covers setup decisions and configuration; the three usage guides provide
flow-specific operational guidance. A single implementation-guide reference does
not replace those usage guides. Use each guide's parent page rather than adding
duplicate entries for its introductory topics. Add a topic-level reference only
when it needs distinct applicability or exclusions.

Source selection: [Product Guidance Documentation in FSCR](https://confluence.oraclecorp.com/confluence/display/SCMA/Product+Guidance+Documentation+in+FSCR).
The listed topic links were resolved to their corresponding public Oracle guides.
Oracle's unversioned SCM documentation landing page resolved to release 26D when
checked on 2026-10-28. Recheck the latest available release before applying
release-sensitive guidance; these references do not establish a target
environment's release or authorize setup changes.
